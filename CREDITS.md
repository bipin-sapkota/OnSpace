# Third-party assets

All third-party content used by OnSpace is CC0 or public domain. Everything else (terrain, planets, player ships, station hulls, audio, music, UI) is generated procedurally by the game.

- **Stylized Nature MegaKit** — Quaternius — CC0 1.0 — https://quaternius.com (fetched from https://github.com/Noisemaker111/jgengine/releases/download/packs/quaternius-quaternius-stylized-nature.zip)
- **Modular SciFi MegaKit** — Quaternius — CC0 1.0 — https://quaternius.com (fetched from https://github.com/Noisemaker111/jgengine/releases/download/packs/quaternius-quaternius-modular-scifi.zip)
- **Ultimate Animated Animals / Ultimate Monsters** — Quaternius — CC0 1.0 — https://quaternius.com (fetched from https://github.com/Noisemaker111/jgengine)
- **KayKit Space Base Bits** — Kay Lousberg — CC0 1.0 — https://github.com/KayKit-Game-Assets/KayKit-Space-Base-Bits-1.0
- **NASA 3D Resources** — NASA — Public domain (NASA media usage guidelines) — https://github.com/nasa/NASA-3D-Resources
- **PBR materials** (Grass004, Ground003, Ground022, Ground010, Rock023, Rock005, Snow004, Ice002, Gravel015) — ambientCG (https://ambientcg.com) — CC0 1.0

NASA models are provided under NASA's media usage guidelines (https://www.nasa.gov/nasa-brand-center/images-and-media/); use does not imply NASA endorsement.

Rebuild with `npm run assets` (downloads into `.asset-cache/`, bakes into `public/assets/`).
